# 🎮 PS Store — Калькулятор цен на игры

Статический сайт (чистый HTML/CSS/JS), который ищет игру по названию в
**PlayStation Store** и показывает её цену в выбранной стране.

**Поддерживаемые страны:** 🇺🇦 Украина · 🇹🇷 Турция · 🇵🇱 Польша · 🇺🇸 США · 🇮🇳 Индия

## Возможности

- 🔍 Поиск игры по названию (с подсказками-примерами).
- 🌍 Выбор страны PlayStation Store — цена выводится в валюте этой страны
  (UAH, TRY, PLN, USD, INR).
- 💱 Пересчёт цены в удобную валюту (USD, EUR, UAH, PLN, TRY, INR, RUB) по
  актуальному курсу.
- 🎯 Точная цена со страницы товара: цена подтягивается напрямую со страницы
  самой игры в PlayStation Store, а не только из поисковой выдачи.
- 🕒 Понятно, **когда** и **какая** цена: под каждой ценой показывается время
  проверки («проверено 22.10.2026, 19:45»), есть кнопка «Обновить цену» и
  история изменений цены (хранится локально в браузере).
- ⚖️ Сравнение цены одной игры сразу в 5 странах с подсвечиванием самого
  дешёвого варианта.
- 🔗 Кнопка перехода на страницу товара в официальном PlayStation Store.
- 📱 Адаптивный дизайн (телефон/планшет/ПК), работает без сборки и без зависимостей.

## Как это работает

| Что | Откуда |
| --- | --- |
| Поиск игр | Официальный поисковый API PlayStation Store (`store.playstation.com/store/api/chihiro/…`), CORS открыт, ключи не нужны |
| Точная цена | Страница товара того же API (`…/container/{страна}/{язык}/999/{id}`) — цена берётся напрямую со страницы игры |
| Курсы валют | `open.er-api.com` (бесплатно, без ключа, кэш в localStorage) |
| Обложки игр | CDN PlayStation (`apollo2.dl.playstation.net`) |

Весь код выполняется в браузере, сервер не нужен — подходит для GitHub Pages.
Если прямой запрос к API блокируется, сайт автоматически повторяет запрос и
пробует несколько бесплатных CORS-прокси.

### Откуда берётся цена и когда она актуальна

1. Сначала цена берётся из поисковой выдачи.
2. Затем для найденных игр цена **перепроверяется по странице самого товара** —
   именно там видны актуальные цены и скидки, которых в выдаче может не быть.
   Под ценой появляется отметка «проверено ДД.ММ.ГГГГ, ЧЧ:ММ».
3. Кнопка **«Обновить цену»** в карточке игры повторно запрашивает страницу
   товара — удобно, когда магазин обновил цены, а страница сайта открыта давно.
4. Каждая проверка запоминается в `localStorage`. Если цена изменилась —
   в карточке появляется блок **«История изменений цены»** (было → стало, с
   датой), а в списке результатов — пометка «цена изменилась».

Одна и та же игра в магазине часто продаётся несколькими товарами (обычное
издание, DLC, бонусные версии). Если конкретный товар в стране не продаётся,
сайт показывает цену одноимённой редакции с пометкой «другая редакция».
Отдельный случай — версия «бесплатно по подписке» (PS Plus): в этом случае
показывается цена обычного издания, а в подписи уточняется, что по подписке
игра бесплатна.

### Как ищется нужная игра

Поиск в PS Store работает как «ИЛИ» по словам, поэтому запрос чистится:
убираются артикли и служебные слова («the», «of», «edition»), а слишком короткие
и чисто цифровые слова отбрасываются. Затем берётся несколько страниц выдачи,
а игры ранжируются на клиенте: точное совпадение названия → вхождение названия →
совпадение отдельных слов.

Дополнительно учитываются:

- **диакритика** — «God of War Ragnarök» находится по запросу «ragnarok»;
- **номер части** — для «fifa 24» подходит именно «EA SPORTS FC 24», а не «FC 25»;
- **переименования** — «FIFA» = «EA SPORTS FC»;
- **жёсткий фильтр мусора** — по запросу «The Witcher 3» больше не показываются
  случайные «Wild Arms 3» и подобные совпадения по отдельному слову.

Если в выбранной стране товар есть в каталоге, но не продаётся, в карточке
показывается **«Нет в продаже»**.

1. Зайдите на [github.com](https://github.com) → **New repository**.
   - Имя: например `playstation-price-calculator`.

   (или *Add file → Upload files*).

7. Через 1–2 минуты сайт появится на адресе вида:
   `https://ВАШ-USERNAME.github.io/playstation-price-calculator/`

## Возможные проблемы

- **«Не удалось загрузить данные PlayStation Store»** — подождите 5–10 секунд
  и нажмите «Повторить». Sony иногда ограничивает частоту запросов; сайт сам
  повторяет запрос и использует запасные прокси.
- **«Ничего не найдено»** — в некоторых странах игра может просто не продаваться
  (например, The Witcher 3 не представлен в украинском магазине). Попробуйте
  другую страну.
- **«Нет в продаже»** — товар есть в каталоге, но в этой стране у него нет
  цены (например, снята с продажи). Если игра продаётся в другой редакции,
  рядом с ценой появится пометка «другая редакция».
- **Игра показывается как «бесплатно по подписке»** — это версия для PS Plus.
  Цена обычного издания всё равно показана рядом.
- **Цена не совпала с ценой в сторе** — на странице товара может быть
  действующая скидка. Нажмите «Обновить цену», чтобы перепроверить цену
  прямо на странице товара, и «Открыть в PlayStation Store» — чтобы увидеть
  итоговую сумму со скидкой.
- **В сравнении страна показывает «не найдено»** — если в магазине страны игра
  переведена на местный язык (например, в Польше это «Wiedźmin 3: Dziki Gon»),
  поиск по английскому названию её не находит.
- **Курс валют не показывается** — обновите страницу: источник курсов
  бесплатный и иногда временно недоступен.
