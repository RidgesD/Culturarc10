# 🎮 Игры GoodStore — каталог по жанрам, озвучке и рейтингу PS

Интерактивный каталог игр для PlayStation (Avito GoodStore): **773 позиции, 21 жанр + разделы «Сплит-скрин» и «Кооперативные игры»**.

Один самодостаточный `index.html` — без сборки, без зависимостей, без интернета после загрузки. Тёмная тема.

## Возможности

- 🌙 Тёмная тема, крупный читаемый шрифт
- 🔍 Поиск по названию и описанию
- 🏷 Фильтры по жанру, типу озвучки и **рейтингу**, быстрая навигация по жанрам
- ⭐ **Рейтинги PlayStation Store** — у 736 игр указана пользовательская оценка PS Store (звёзды и количество оценок)
- 🏆 **ТОП-5 / ТОП-10 / ТОП-15** — показывает самые высокооценённые игры внутри выбранного жанра
- 🎚 Фильтр по рейтингу: «★ 4.5 и выше», «★ 4.0+», «★ 3.5+», «Только с оценкой», «Без оценки»
- 📖 Разделы «жанр → озвучка» с цветными метками:
  - 🟢 Русская озвучка
  - 🔵 Русские субтитры и интерфейс
  - ⬜ Английский язык
- 🕹 Отдельные разделы **VR1 (PS4)** и **VR2 (PS5)**
- 🖥 Раздел **«Сплит-скрин»** — кооператив на одной консоли, с описанием как играть вместе
- 🌐 Раздел **«Кооперативные игры»** — совместная игра по локальной сети или интернету
- 📋 Кнопка копирования списка игр в буфер обмена (от 1 до 20 шт., с описанием или без, с учётом фильтров и ТОП)
- 📱 Адаптивная вёрстка, работает на телефоне

## Структура репозитория

```
goodstore-catalog/
├── index.html   # весь каталог (данные + стили + логика)
├── README.md    # этот файл
└── .nojekyll    # отключает сборку Jekyll на GitHub Pages
```

## Публикация на GitHub Pages

1. Создайте новый репозиторий (кнопка **+** → *New repository*), например `goodstore-catalog`.
   Репозиторий должен быть **Public**.
2. Загрузите в него файлы `index.html`, `README.md` и `.nojekyll` (кнопка *Upload file*).
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка: **/ (root)**
5. Нажмите **Save**. Через 1–2 минуты каталог будет доступен по адресу:

   `https://<ваш-логин>.github.io/goodstore-catalog/`

## Обновление данных

Замените `index.html` на новый файл и закоммитьте — страница пересоберётся автоматически.

## Локальный запуск

Просто откройте `index.html` в браузере двойным кликом — сервер не нужен.

## Источник рейтингов

Оценки — пользовательские рейтинги PlayStation Store (магазин Великобритании), собраны автоматически в октябре 2026 г. У части игр (старые, региональные, подписки) оценки в PS Store отсутствуют — для них показан знак «—».
